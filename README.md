# Astral Planner

A dark-theme daily life planner website inspired by Genshin-like fantasy UI motifs.

## What this version includes

- Layered dark celestial visual style
- Real-time clock and live day-progress indicator
- Quest-based task manager (add, complete, delete)
- Priority labels (High / Medium / Low)
- Local storage persistence for tasks and ritual checkboxes
- Focus timer (25-minute session with start/pause/reset)
- Dynamic stats panel and rotating motivational quote

## Run locally

Open `index.html` in your browser.
